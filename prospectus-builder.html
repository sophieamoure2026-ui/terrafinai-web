PROSPECTUS BUILDER — CREXI VAULT PATTERN, STATIC-SITE EDITION

Prospectus Builder

Ingest an offering memorandum, rent roll, or financial summary → extract structured data → auto-generate the offering document. This is the workflow that makes the 48-hour Certified Prospectus operational instead of manual — the same workflow shape as Crexi Vault + Create, applied to off-market trophy assets.

What this build is: a rule-based extraction pass (currency amounts, keys, percentages, years, asset types) plus structured fields you confirm — running entirely in the browser. What it is not: AI extraction. Production AI document extraction needs a backend service (see DECISIONS.md). Nothing extracted here is treated as verified until the deal team checks it against source documents — extraction is not verification.

No extraction yet. Paste source text and run the extractor — the structured fields appear here for review and correction before anything is generated.

The generated offering document appears here after extraction. It follows the site's offering-document format: teaser, key facts, verification checklist, process. Downloadable as HTML or plain text.
